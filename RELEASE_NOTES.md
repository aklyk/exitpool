# exitpool 2.0.0

Первый выпуск под новым именем (бывший happ-service).

- AWG-выходы без Docker: туннель в своём сетевом пространстве, реле Xray без привилегий, fail-closed,
  готовность по проверке через туннель, отказ замечается за ~30 с.
- Режимы памяти AWG-выхода 32 / 64 / 128 / своё, у каждого выхода свой; честная оценка памяти.
- Команда `exitpool`: меню и команды для всего, что умеет веб; веб-интерфейс — по желанию.
- Мастер 2.0: сканирование сервера, выбор частей с бюджетом памяти, AWG прямо в мастере, три режима связи с 3x-ui.
- Бинарники AWG для Ubuntu 24.04 amd64 в релизе (SHA-256), прокси для скачиваний, сборка из исходников как запасной путь.
- Перенос с happ-service 1.x: по одному выходу с откатом, теги и порты для 3x-ui прежние.
