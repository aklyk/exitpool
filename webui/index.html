Добавить AWG-выход

Профиль AmneziaWG (.conf) с полным туннелем, как его выдаёт провайдер. Ключи хранятся только на сервере и в браузер не возвращаются. Один профиль — один выход: не включайте его одновременно на телефоне. Новый выход появится в панели 3x-ui после добавления socks-исходящего с тегом и адресом, показанными на карточке (10.250.N.2:порт — доступен только с этого сервера).

Текущая подписка

Заменить подписку

Вставьте новую ссылку happ://crypt5/…. Временный Happ прочитает профили, затем вы выберете профиль для каждого выхода. Теги и порты выходов в панели не меняются.

Резервные копии

Создаются перед каждой заменой подписки. Восстановление возвращает ключ, настройки и импортированную подписку, выходы перезапускаются по одному.

Панель 3x-ui (необязательно)

Показывает на карточках, какой выход сейчас выбран балансером, и задержку по оценке балансера. Токен хранится только на сервере и в браузер не возвращается; используются только запросы на чтение.
